# 古船模型帆索校准 · 施工交接记录

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 交接规则

每个索位一份连续的施工交接履历：

- **交接四要素**：下料长度（真船 mm）、麻线批号、捻向（Z/S）、接手人；交班人和张力读数随记录留档。
- **换算与裕量**：下料长度按模型比例换算成模型 mm，与图纸模型实长比较；超出 +裕量 即**停待复尺**，复测签字通过前不能标记校准完成（不允许“先算校准完成”）。
- **换班续记**：索位仍在进行中（待复测 / 停待复尺 / 复测不合格）时，新班次直接在原记录后追加一条；前一位师傅的张力读数和历史结论全部保留在履历里。复测合格封档后不得再追加。
- **复测签字**：在停待复尺 / 待复测 / 复测不合格状态下可提交实测长度与签字人；实测差值在 ±裕量 内为合格，合格后才能标记校准完成。
- **交付确认**：所有索位均完成复测签字并校准后，模型才可置为「已交付」；否则页面顶部列出每个缺项索位的名称和原因。
