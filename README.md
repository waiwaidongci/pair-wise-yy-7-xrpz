# 古船模型帆索校准

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 帆索施工交接

- **索位记录**：每个索位一份施工交接记录，逐班次追加下料长度(mm)、麻线批号、捻向(S捻/Z捻)、交班人、接手人、张力读数。新班次只能续记在原记录内；同一模型下索位名称不可重复，防止重复裁线。
- **比例换算与裕量**：索位录入原型长度，系统按模型比例换算（原型长度 ÷ 比例分母，如 1:48）。最近一次下料长度与换算长度的偏差绝对值越过裕量（索位裕量，缺省沿用模型裕量 5mm）时，索位自动置为「停待复尺」，不能标记校准完成。
- **复测签字**：停待复尺的索位由复测人填入实测长度并签字；复测长度仍越裕量则拒绝签字。签字后索位转为「复测完成」，此前各班次的交接记录与张力读数完整保留在履历中；复测后若再续交接且超差，索位重新转为停待复尺。
- **交付确认**：模型全部索位复测完成后，页面给出「可以交付」确认按钮；否则列出缺项索位名称及当前状态，服务端同样拦截「已交付」状态变更。
